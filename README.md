📚 Learning Management System (LMS)

This is a responsive Learning Management System website built using modern web technologies. It allows users to browse courses, enroll, and manage learning progress easily. The project focuses on providing a simple, user-friendly interface for both students and instructors.

✨ Features

User-friendly dashboard

Course listing and details page

Login and registration system

Responsive design for all devices

Easy navigation and modern UI

🛠️ Technologies Used

HTML5, CSS3, JavaScript (Frontend)
